PRIVATE TOKEN
如何创建 GitHub 访问令牌？

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens。选择你的作品集仓库，并授予 Contents: Read and write。令牌不会保存到浏览器本地存储。

数据保存说明

作品保存在仓库的 projects.json，网站介绍保存在 site-settings.json，封面图保存在 assets/covers/。提交成功不代表前台已完成部署；如页面尚未更新，请稍等片刻后刷新。

建议仅在可信任的个人设备上使用管理后台。离开前可在「连接设置」中清除令牌。
